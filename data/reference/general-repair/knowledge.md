# 通用維修件精簡參考

此類作為一般維修零件與不明小五金的 fallback，包含 O-ring、墊片、束環、彈簧、卡扣、銷、襯套、軸套、間隔件與其他常見小零件。

辨識時優先看：
- 功能形態：密封、夾持、回彈、定位、間隔、止退、支撐或減震。
- 材質外觀與構造：橡膠／塑膠／金屬、開口／閉口、彈性結構、孔／槽／卡爪等。
- 如果物件其實明顯屬於水管、電氣、緊固或建築五金，應在最終 category 主動改正，不要因為本 reference 是 fallback 就硬套。

規格原則：
- O-ring、墊片、襯套等通常需要內徑、外徑、厚度與材質才能採購；照片沒有尺度時不要虛構尺寸。
- 軸承或精密機械件若沒有刻印與尺寸，不要猜特定料號。
- 採購描述以功能名稱＋材質外觀＋需量測的尺寸欄位為主。
