# HCSI 通用辨識原則

這份內容是辨識方法，不是待辨識物件，也不是規格資料庫。

## 證據層級

- **直接可見證據**：清楚的文字、刻印、形狀、接口、驅動結構、顏色、數量與可觀察構造。
- **有依據的目測估計**：比例、相對大小、常見形式與形態組合，可用來提出最可能候選，但不能假裝是量測值。
- **無法確認**：需要實際尺寸、內部構造、額定值、材料牌號、壓力／電流等級或包裝資訊才能知道的內容。

## 判讀原則

1. 先辨識物件功能與整體形態，再處理細部規格。
2. reference 只用來提醒具有辨識力的特徵，不得因某物件出現在 reference 就提高它的可信度。
3. 不可由單純像素大小推導真實 mm / inch；沒有可靠尺度時只能做目測估計。
4. 不可用「常見」取代照片證據，也不可補寫照片看不到的品牌、型號、額定值與材料等級。
5. 若存在近似候選，優先找出最能區分兩者的可見特徵，再做最後選擇。
6. 一張照片足以做有意義判斷時，直接給出最可能答案並標示不確定性；只有影像本身不可用時才判定無法辨識。
7. 最終輸出應同時服務「知道這是什麼」與「拿去五金行／材料行怎麼描述」兩個目的。
